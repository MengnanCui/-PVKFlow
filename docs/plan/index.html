1目标与边界

一个本地运行的高通量实验数据平台：双击启动、不联网可用、数据全在自己机器上。 当前的数据对象是原位吸收光谱矩阵（波长 × 时间，来自仪器导出的 Data.csv）。

层内容本期
① 数据处理导入、解析、热力图、叠加谱、膜厚（干涉条纹 FFT）、谱斜率 / 波段积分、批处理与对比做扎实
② 数据存储工作区、去重、样品身份、关键结果长表、运行记录可追溯、对比历史做扎实
③ 构效关系任意两个字段做 X / Y、相关性、分组比较、异常识别、模型总结只留入口与数据形态

明确不做（截至本版）

  • 不静默监听目录、不自动跑处理 —— 所有处理都要你点一下
  • 不打包成单个 exe（需要先装 Python 3.11+）
  • 没有登录和权限体系，所以只监听 127.0.0.1
  • 模型写的代码不执行；模型的操作只渲染成卡片，你点了才生效
