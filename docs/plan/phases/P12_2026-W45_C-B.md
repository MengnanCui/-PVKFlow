## CI 第一次真跑 run.bat：同事会装不上

C 组里最有价值的一件事。run.bat 原来用 `py -3` 找 Python，拿到的是电脑上**最新**的那个；
而原来钉的 numpy / pandas / pydantic-core / Pillow **在 3.14、3.15 上都没有 Windows 预编译包**。
pip 于是在没有编译器的机器上从源码编译，卡在「正在安装依赖」—— CI 上 8 分钟没动（收尾时清掉的孤儿进程是 VC++ 编译器的）。
**python.org 首页现在给的就是 3.15**，同事照 README 装会卡在同一处。

修法：依赖升到 3.11–3.15 上都有预编译包的版本（含 pandas 2.2 → 3.1）；run.bat / run.sh 从 3.15 到 3.11 从新到旧挑；
装依赖只装预编译包（没有就立刻报错，不编译）；版本范围写在四处，测试守着一致。

**结果**：CI 的 Windows 上 run.bat 挑到 3.15.2，**29 秒**建好环境、装完依赖、起服务、首页能打开。
