## 构效关系第一版长什么样

- **散点图**：一个样品一个点、按批次着色、虚线是最小二乘直线；指到点上看是哪个样品，点一下打开它。
  X / Y 任选、一键交换；范围可以是全部样品，或者**数据处理页筛出的 / 勾选的**
- **统计**：样品数（以及多少个只有一边的数，不在图上）、皮尔逊 r + 95% 置信区间 + p、斯皮尔曼 ρ + p；
  样品太少或某一列都一样时**不给数、说为什么**；字段单位不一致时警告；一段人话说明 r / ρ / p，和「相关不等于因果」
- **按批次的箱线图**：离群的样品单独画出来，悬停有名字、点了打开，也列在下面
- 逐个样品的表、下载（图片；数据是每个样品一行，带样品名和批次）

**统计没有装 scipy**（装机体积），p 值的 t 分布是自己算的。在另一个装了 scipy 1.18.1 的环境里算了 7 组数据的参考值，
逐个对上，最大相对误差 7×10⁻¹³（p 小到 10⁻⁷⁶ 也对得上），参考值原样进了测试。
