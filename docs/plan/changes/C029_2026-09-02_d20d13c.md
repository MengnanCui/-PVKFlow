## 当时的说明（原文）

你要一份「渲染之后的 html」来找问题。现在要看界面只有一条路 ——
装 Python、起 FastAPI、开浏览器。想在没环境的机器上看一眼、想把界面发给别人
指指点点、想留一份「这一版长什么样」，都做不到。

`.venv/bin/python tools/bake_offline.py` 产出**一个自包含的 html**（2.3 MB）：
CSS / Inter 两个子集 / 25 个模块全部内联，后端每个接口的**真实响应**也录在里面，
`fetch` 从录好的那份取。双击就开。图能悬停、滑块能拖、ⓘ 能点开、明暗能切。

**不碰 web/ 和 app/ 里任何一行。** 离线版是从现在跑着的代码烤出来的，
不是另一份实现 —— 一旦要改源码才能烤，烤出来的就不是你正在跑的那个界面了。

几处值得写下来的：

**不引 esbuild/rollup。** 这份前端没有 node_modules，为了烤一个离线版
去引一整条 JS 工具链，是把「零依赖」这条最重要的性质丢掉。而这份代码的模块
语法窄得刚好够手写：只有两种 import、一种 export，没有动态 import()、
没有 export default、**而且无环**（现场跑过图检查）。无环意味着依赖总是先于
使用者求值，一个注册表加一层 IIFE 就够。这三条前提每次烤都复核一遍，
以后有人写出一个环，当场报错 —— 而不是烤出一个静默坏掉的产物，
让你对着它查一个源码里根本不存在的 bug。

**没录到的接口只认完全相同的地址。** 「找不到就退回按路径匹配」听起来友好，
实际上是这东西能犯的最严重的错：你把时刻滑块拖到 5 s，快照里只有 18–19 s，
按路径一匹配就把 18 秒的数字顶着「5–6 s」的标题画出来 ——
你会对着一组错的数下结论。没录到就返回平台自己那套错误结构，
errorBox 会把「这是离线版，××× 没有录进快照」画在该出现的位置上。

**热力图要单独拦一道。** 它走 SVG `<image href>` 和 `new Image().src`，
两条都不经过 fetch —— 只拦 fetch 的话三张热力图全是空的。
所以在 setAttribute 和 src setter 那一层再换一次 data: URI。

**时刻滑块整条时间轴都录。** 那是这一轮刚做的东西，拖不动就没法查它的问题。
一条切片响应才一两 KB，21 秒也就三十来 KB，比一张热力图还小。
录的时候用 `URLSearchParams` 拼 URL，和 api.js 逐字一致 ——
拼原始字符串的话 `:` `,` 的编码对不上，明明录了却说没录进来（第一版就这么错的）。

**侧栏状态行改成「离线版 · 没有本地服务」。** 绿色的「本地服务正常」和横幅上的
「离线版」自相矛盾；红色的「连不上本地服务」又像是坏了。两个都不对。

产物里绝不能带密钥或内网地址：出文件之前断言一遍整份快照 ——
没有 sk- 开头的串、没有公共网关之外的主机名，命中就中止不出文件。
实测产物里只有 127.0.0.1、w3.org（SVG 命名空间）和四个公共服务商。

验证（全部从 **file://** 打开，不是 http —— 双击能不能跑的坑全在这边）：
六个主页面各自渲染出不同内容、零 console error；对比页两张膜厚图 / 三组模块参数 /
9 条图例 / 悬停读数框带线型；滑块拖到 0、3、7、12、18、20 秒都出数；
样品页三张热力图全部换成 data: URI；ⓘ 浮层、明暗切换正常；
五档屏宽 × 明暗均不横向滚动。341 项 pytest 不受影响。

顺带一条：`web/js/components/form.js` 没有任何模块 import 它，是死代码。
这次没动它，先记下来。
