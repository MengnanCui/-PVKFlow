## #26 上传和装模块卡住整个界面（低）

这两个接口写成了 `async`，里面却全是阻塞的活（解析文件、跑一遍模块、写库），直接在服务的事件循环里做 ——
期间别的请求（包括界面上的进度条轮询）全得等。改成普通函数，FastAPI 会放进线程池。
- 真起一个服务测：上传卡在解析里的 1.5 秒内打健康检查。**旧代码等了 1.30 秒，现在立刻返回**
- 再加一条守着：**所有**路由都不许是 `async`（这个平台的路由全是阻塞的活）。旧代码上它正好点出这两个
- 写这条测试时发现新版 FastAPI 不再把子路由摊平在 `app.routes` 上，第一版测试其实什么都没查到 —— 改成一层层往下找，并断言真的找到了 50 个以上

## #16 点「停止」后回答不落库（中）

点停止 = 框架在 `yield` 那儿把生成器关掉，存消息的代码在循环后面，一行都不会跑 —— 那条消息永远是空白的「生成中」。
- 存消息挪进 `finally`：已经说出来的字存下来，标「已停止」，并关掉模型那头的流（别白占着网关）
- **光这样还不够**：真起一个服务、半路断开，4 秒后消息仍是空白。原因是 Starlette 发现断开后只是不再往下取，并不关生成器，
  `finally` 要等垃圾回收哪天碰巧跑到。加了一个小的 `StreamingResponse` 子类，流一结束（不管是说完还是断开）就亲手关掉，
  并且不许被这次请求的取消打断
- 浏览器里实测：问一个慢慢回答的问题、点停止 —— 库里 40 个字、标了已停止；刷新页面重开这个对话，看得到那 40 个字和「（已停止）」

## #25 时区混用（低）

文件夹名里的时间戳是仪器的本地时间；文件夹名里没有时间戳时退回文件修改时间 —— 原来存的是 UTC（带 `+00:00`）。
按时间筛选是字符串比较，混着存，没有时间戳的那几个在中国就偏 8 小时。
- 退回的那一路改成本地时间、不带时区，和文件夹名同一种写法
- **第 2 步数据库迁移**把已经存成 UTC 的换算成本地时间（用这台电脑的时区 —— 和当初导入时是同一台）。文件夹名里来的不动，认不出来的不动，能重跑
- 在测试工作区上真的升级了一次：版本 1 → 2，先备份，文件夹名里的时间一个没变

## #28 构效关系页的字段表（低）

- 只列前 40 个、标题却报全部数量 → **全部列出**
- 同一个字段换了单位就列两行 → 后端一个字段只给一行，所有单位都在里面；**不止一个单位时标「单位不一致」**（这时的最小 / 最大是把不同单位的数混在一起算的，鼠标停上去有说明）
- 没显示中文名 → 字段名下面一行中文名
- 总览、存储、构效关系三页都列字段，原来各写一份，现在共用一个组件；存储页「N 个不同字段」原来按（字段, 单位）多算了，现在是真的字段数；
  总览页只摆最常见的 12 个，现在会说「最常见的 12 个，共 N 个」

## #29 下载（低）

- **CSV 公式注入**：曲线名来自文件夹名和样品名，是别人给的数据。以 `= + - @`、制表符、回车开头的文字格子，Excel / WPS 打开时会当成公式执行。
  这种格子前面加一个 `'`（Excel 就当纯文字显示）。**只动文字** —— 数（包括 -0.5 这种负数）原样写，不然一列数就全变成文字了。
  拼 CSV 的代码挪进了一个不碰页面的小文件（`web/js/csv.js`），在 node 里有 9 条测试
- **下载热力图不看状态码**：服务端出错时把那段错误 JSON 存成了一个打不开的 `.png`。现在先看状态码，出错就提示「下载失败：原因」、不下载

## #30 无障碍（低）

- **样品行能用键盘选**：Tab 进列表，上下键移动，空格勾选，Shift+空格范围选，Shift+上下边走边选，回车打开 —— 和鼠标的手势一一对应。
  列表是 `listbox`、每行是 `option`。虚拟列表滚动时会把行整块重画，焦点原来会掉回页面上；现在重画后放回同一行（实测连按 25 次下键，焦点在第 25 行）。
  页面上的操作提示加了一句「键盘：上下键移动、空格选、回车打开」
- **弹窗**：是 `dialog`、标题就是它的名字；Tab 只在弹窗里转（实测 15 次没跑出去）；关掉后焦点回到打开它的那个按钮
- **提示**：提示区是 `aria-live`，读屏软件会念；出错的那种用 `role=alert`，会打断着念

## 我自行决定的
- **D-89** 装模块的规则：同 id = 升级（换掉它自己的目录）；目录名撞上另一个正常加载的模块 = 换目录名；撞上装坏了的 = 原地换掉；平台自带的 id 不许覆盖。
  解压上限 **32 MB / 500 个文件**（数是我定的：模块只该有代码，平台自带的两个模块加起来不到 100 KB）
- **D-90** 下载文件名用 RFC 5987 的 `filename*` + ASCII 兜底名（非 ASCII 字符换成 `_`）
- **D-91** 所有路由一律写成普通函数（放线程池），由测试守着
- **D-92** 被打断的回答：已经说出来的字照存，`meta.aborted = true`，界面显示「（已停止）」
- **D-93** `measured_at` 一律存本地时间、不带时区；已经存成 UTC 的由迁移按**这台电脑的时区**换算（**建议你确认** —— 这改的是库里已有的时间。只影响文件夹名里没有时间戳、退回文件修改时间的那几个样品；
  如果你的数据曾经在另一个时区的电脑上导入、再把工作区拷过来，换算会差那个时区差）
- **D-94** 字段表一个字段一行；单位不一致时标出来但照样给最小 / 最大；中文名取出现最多的那个
- **D-95** CSV：以 `= + - @ \t \r` 开头的**文字**前面加 `'`；数原样；**`NaN` 写成空格子**（原来写的是字符串 `NaN`，Excel 里是文字、画图时当 0 —— 空格子是 CSV 里「缺值」的通行写法，pandas 两种都认）
- **D-96** 键盘操作的键位（空格 / Shift+空格 / 回车 / 上下 / Shift+上下），和鼠标的手势一一对应
