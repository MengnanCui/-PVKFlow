## 做了什么

### L-1 每打开一次 AI 抽屉就新建一个空的「新对话」（P12 浏览器验收时发现）

原因：抽屉一打开、一点「新对话」，就立刻在库里建一个会话 —— 一句话没说也算。每刷新一次页面再打开就多一个，历史里攒一串「新对话 · 0 条」。

- **抽屉**：打开、点「新对话」只清屏；**第一次发送时才在库里建**。连按两下回车只建一个、只发一句（建的过程中输入框已经清空；没建成就把话还给你）。还没说话时菜单里不摆「重命名 / 导出 / 删除」—— 库里还没有这个对话
- **历史列表**：不列一条消息都没有的会话（发送可能在开流之前就失败 —— 比如还没配模型 —— 那样仍会留下一个空的）。术语 ⓘ 的线按术语取时照列：ⓘ 靠它找回这个词下面问过的话
- **第 3 步数据库迁移**：已经攒下的空会话一次清掉（术语 ⓘ 的线不动）。在测试工作区上真跑了一次：先备份，22 个会话里 10 个空的清掉
- 改了一条旧测试的期望：原来写着「不带 topic 全都列出来」，现在还没问过一句的术语线不进抽屉的历史（ⓘ 自己按术语取照样拿得到）

**浏览器实测**（新脚本 `tools/qa/l_check.js`，直接数库里的会话）：刷新 3 次、开关抽屉 9 次以上、点「新对话」3 次 —— **库里会话数不变**；
同一份脚本对旧前端跑：同样的操作多出 6 个空会话，7 条里挂 4 条。

### L-2 批处理导出 zip 里的 data.csv 没有公式防护

前端「下载数据（CSV）」上一轮已经防了；导出给 plot.py 用的 data.csv 没防 —— 那时的顾虑是名字前加 `'` 会让图例上也多一个 `'`。
现在两头一起改：data.csv 里以 `= + - @`、制表符、回车开头的**文字**前面加 `'`（数原样），**导出的 plot.py 读回时去掉**。zip 里的 README 写明了这一点。
- 测试：把一个样品名改成 `=HYPERLINK(...)`、一个批次改成 `@evil`，跑批处理、导出 —— data.csv 里没有一个名字以 `= + - @` 开头；**真的执行导出的 plot.py**，读回来的是原名，没有残留的 `'`
- 同一条规则现在写在两处（前端 csv.js、后端 script_export），加了一条测试：13 个值两边逐个比对，做的事必须一样

### L-3 其余页面的键盘操作

写了一个扫描：找出「挂了点击、但不是按钮 / 链接 / 表单控件」的元素。全前端只有一处真漏的：**对比历史的行**只能用鼠标点。
现在 Tab 走到那一行、回车或空格就打开（行的焦点样式 CSS 里早就写了，只是行从来拿不到焦点）。
这个扫描做成了测试 `tests/test_frontend_a11y.py`：以后写出「只能鼠标点」的元素，提交前就会红（对旧的 history.js 跑：正好点出那一行）。
另外两处是有意的（浮层只是挡住冒泡、遮罩用 Esc 也能关），写进了豁免清单并说明理由。

### L-4 控件生成两份

样品页的模块面板和对比页的配方面板，各有一份「把模块的控件声明变成滑块 / 下拉 / 勾选框」的代码，几乎逐行相同。
合成一份 `figure.specControl`，两边只说「值从哪读、写到哪、拖动 / 松手时做什么」。浏览器验收里两边的控件都在、拖动仍然只在松手时打一次后端。

### L-5 `xyChart` 一个函数约 440 行 —— 这次不拆

它是纯结构问题，没有用户看得见的毛病；又是全平台用得最多的画图代码，浏览器验收只能间接覆盖它。
做 E 组（构效关系第一版要加散点图）时要动它，那时一起整理更稳。

## 我自行决定的
- **D-99** AI 抽屉的会话等第一次发送才建；没说过话时菜单里不摆重命名 / 导出 / 删除
- **D-100** 抽屉的历史列表不列没有消息的会话；术语 ⓘ 的线按术语取时照列

- **D-105** `xyChart` 这次不拆，等做 E 组时一起整理
