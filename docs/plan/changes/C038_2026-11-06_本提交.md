## 做了什么

- `app/ai/context.py` 新增「曲线摘要」：
  - 数据来自**最近一次跑过这个样品的批处理**的长表（和关键结果「当前值」同一个口径）
  - 每条能画的曲线都进来：膜厚、积分、斜率，以及同事模块声明的曲线；膜厚另附每段的「可信比例」
  - 按时间**等分成 N 段、每段取平均**（不是抽点）；N 由总预算倒推，12 到 30 段之间
  - 每条曲线写成一行数字（4 位有效数字），不用 json 数组 —— 后者会被 `indent=2` 拆成一个数一行
  - 放在事实包的**最后**：超长时从尾部截断，先截曲线，不截标量表和对比诊断
  - 没跑过批处理的样品单独列出「没有曲线的样品」，不编
  - 范围超过逐条阅读上限（40 个）时和样品明细一样不给
- 平台三条内置曲线的纵轴标签挪到 `app/batch.py BUILTIN_Y_LABELS` 一份，对比页 / 导出 / AI 共用（原来曲线目录里只剩 `slope`、`integral` 这种列名）
- 系统提示补一条读法：曲线摘要和时间行一一对应；读膜厚要对照可信比例；摘要只够看趋势，不要读出精确到个位的数
- 「AI 能看到什么」的说明同步改：抽屉空态、术语 `ai_scope`、README
