## 做了什么

### 文件（`app/agent/files.py`，照 IFlow 的 `lib/server/serverFs.ts` + `tools/server.ts`）
- **能碰哪些地方**：右侧「它能碰的文件夹」名单。工作区总在、可写，但里面的 `raw/`（原始数据复制件）、`config/`（密钥）、
  `modules/`（功能模块）、`tables/`、`derived/`、`cache/`、备份目录和数据库文件**只读**；你加的文件夹每个单独选只读 / 读写。
  路径一律解析成真实路径再核（`../`、绝对路径、软链都逃不出去）；相对路径从工作区算
- **工具**：`list_files`（列目录，1–4 层）、`read_file`（带行号、分段读，UTF-8 / UTF-16 / GBK 都认，二进制不显示）、
  `search_files`（正则 + 文件名通配）、`write_file`（整文件 `content`，或 `find` + `replace` 改唯一的一段）、
  `file_changes`（改动记录）、`rollback_file`（撤销一次 / 撤销这次对话的全部）
- **写之前备份**：原文件拷到 `workspace/agent_backups/<改动 id>/`，新表 `agent_file_change` 记前后 sha；原子替换；按原编码写回。
  撤销先核对「现在的文件就是这次改出来的那份」，之后又被改过就拒绝（除非 force）；新建的文件撤销 = 删掉
- **打码**：读出来的东西先把 apiKey / token / password 字段、`sk-…`、`Bearer …`、URL 里的口令、私钥块打码，再给模型

### 批处理与任务
- `run_batch`：范围必须指定（sample_ids / batch / q / set_id，或明确 all_samples），配方不给用默认。
  和界面上的批处理按钮走同一个 `batch.submit_batch`（顺手把接口那份校验收成一份）
- `get_task`：看进度，`wait_seconds` 最多 60 秒，跑完了给 run_id；`list_tasks`；`cancel_task`（停在这儿，已跑完的保留）；
  `batch_summary`：几个成功 / 失败、失败原因、每个字段这一次算出来的样品数 / 均值 / 中位数 / 范围
- 等任务时每秒看一眼「停止」；单轮时间上限从 5 分钟改成 10 分钟

### 审批与界面
- 写文件、撤销、跑批处理、停任务都是「会改东西」的（write）：默认停下来问你。审批卡上：
  写文件带**差异**（绿的加、红的删），跑批处理写明几个样品、哪些参数改了、新结果会成为当前值，停任务写明当前进度
- 工具卡上：写了文件的直接有「撤销这次改动」按钮（你点的，不经过模型）
- 右侧新增「它能碰的文件夹」：加文件夹（只读 / 读写）、切换、移除
- 「停止」先通知服务端再断开连接 —— 正在等批处理的那一步也能立刻停
- 系统提示补上：文件夹名单、哪些只读、改文件前先读原文、批处理怎么提交 / 等 / 看结果、别为了「看看」随手跑批处理
