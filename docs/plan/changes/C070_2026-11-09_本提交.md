## 做了什么（bug）
1. **QFLS 切标签筛选被清空**（我在 P17 写的）：每切一次标签、从样点页回来，都会重取整次处理并清空筛选 ——
   和「筛选在标签之间共用」的说法正相反。现在同一次处理已经取过就直接画（也不再每次闪骨架屏）
2. **QFLS「停止」多出一条轮询链**：停止后又手动 tick 一次，toast 和跳转各来两遍。现在只发停止，进度由原来那条轮询接着看
3. **QFLS 取一次进度失败界面就卡死**：现在连续失败 3 次才停，并给「重新查看进度」按钮；处理完后取列表失败也有提示
4. **数据处理页：从样品页回来勾选全丢了**：每次进页面都清空勾选。现在只在改筛选（原来就会清）和切功能时清
5. **两张表没有样式**：时刻切片表、设置页的模块表用了不存在的 `table.table` → `table.data`
6. **对比页「取消钉住」**：没有确认（对话删了之后钉住的就是唯一一份）、失败了没有提示 → 先确认、出错提示
7. **样品页模块列表加载失败时报错框会叠加**，重试成功后旧的也不走 → 固定一格
8. **设置页批量测速离开页面后还在跑** → 接上页面的 signal
9. **重跑标题「undefined–undefined nm」**（没装膜厚模块、老配方又没有波段时）→ 写「改了参数」

## 做了什么（一致性）
- **状态叫法全平台一份**（`ui.js` 的 `STATUS / statusText / statusClass`）：原来五个页面各写一份，
  「失败 / 没跑完」「进行中 / 运行中 / 处理中」「已取消 / 已停止」混用 → 排队中 / 进行中 / 完成 / 失败 / 已停止
- 出错 toast 统一用 `'err'`（原来 `'err'` 和 `'danger'` 混用）
- **数据处理页的「QFLS」那一格**原来标「规划中」、点不动 —— 可侧栏里早有完整的 QFLS 页。现在点它直接去「QFLS 成像」
- QFLS 的箱线图、对比页的三张叠加图接上平台的「下载 ▾」（图片 / CSV），和样品页、构效关系页一致；
  QFLS 的导出改用平台唯一的 `saveBlob`（`download.js`），不再自己写一份
- QFLS 的可点行：回车**和空格**都能打开（原来只认回车）；行里复选框上的按键不再冒泡成「打开样点」（`clickableRow()`）
- QFLS 样点页标题写样点编号（和样品页、批处理页一样）；没给样点时有空状态
- 智能体 `/help` 里补上 `/delete`
