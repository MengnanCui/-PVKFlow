## 做了什么

### 根因：页面没有生命周期（#4 #5 #6 #18 #23 及同类）
页面是常驻的、状态在模块级变量里，异步的东西回来时你可能已经不在这一页、甚至换成了同一页的另一个对象。

- **路由**（`app.js`）：每次进入页面给一个 `signal`（离开即 abort）和 `alive()`；
  自己刚写进地址栏的 hash 在 `hashchange` 里认出来、不再渲染第二遍（**#4**）；`#/settings` 这种写法也认（**#21**）
- **只认最后一次**（`ui.js latest()`）：数据处理页的筛选、存储页搜索、目录浏览、对比页时刻切片、
  通用 `render()`、模块面板的精确结果都用上（**#18**）。模块面板被作废的那次请求负责的面板不会漏：它的 key 留着由下一次带上
- **数据处理页**：拖拽上传的监听同一节点只挂一次（**#5**）；批处理轮询离开就停、不再把你从别的页面拽去对比页；
  取不到进度连续三次才停并说出来（原来一次失败就悄悄停，进度条卡住）
- **对比页**：轮询离开就停，不再改别页标题、不再替换正在看的对比（**#6**）；所有加载离开后不写状态
- **样品页**：连着点开两个样品时先点的那个不会覆盖后点的；离开样品页时摘掉滚动 / 尺寸监听
- **设置页**：存完之后的自动刷新只在你还停在设置页时才做（原来会把你从别的页面拽回来）

### 零散的（#7 #19 #20 #22 #23 #27）
- **#7** AI「用这个范围继续问」：收窄的范围存在抽屉里，下一问带它；范围栏显示「AI 收窄的 N 个 ✕」可撤销；
  点「选中的 / 全部命中的」或开新对话时清掉
- **#23** AI 流式回答途中换对话：先停掉旧回答；旧回答的字只写进它自己那个对话
- **#19** 拖数字滑块：拖动时只本地重画，**松手才打后端**（原来每帧一次）
- **#20** 样品页下载的文件名：读错了字段，一律叫「样品_…」；现在以样品名开头
- **#22** 对比页曲线出错后「重试」：先清掉上一次的错再重来
- **#27** 对比页参数区说明：原样显示的 `**不用**` 改成真加粗；「上面」改成「下面」

## 我自行决定的
- **D-59** 页面生命周期的形式：`ctx.signal` + `ctx.alive()`，由路由在每次导航时发放；而不是给每个页面加 `unmount()` 钩子（改动面更小，现有页面逐处加判断即可）
- **D-60** 「只认最后一次」用取号的方式（`latest()`），不用 `AbortController` 取消请求 —— 取消会让每个调用点都要处理 AbortError；作废响应更简单，代价是后端仍会算完那一次
- **D-61** 批处理轮询：离开页面就停（结果在对比历史里）；连续 3 次取不到才停并提示
- **D-62** AI 收窄范围：存在抽屉的状态里、优先于数据处理页的筛选；范围栏单独一枚可撤销；新对话 / 手动选档时清掉
- **D-63** 把浏览器验收脚本放进仓库 `tools/qa/`（原本只在临时目录）
