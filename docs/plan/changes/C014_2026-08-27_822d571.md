## 当时的说明（原文）

起因是「检查程序的运行 / 一键运行 / 方便输入 api / 数据存哪」这几个问题。
照着走了一遍，发现三个真挡路的东西。

**★ 按子文件夹导入在界面上根本调不到**
scan_folders 后端建好也测过（推送①），/api/files/scan 也认 mode="folders"，
但导入对话框从来没接上去 —— 只能用 Python 走。而「选一个主文件夹，
自动识别子文件夹」正是真实数据的唯一导入方式。
现在对话框里两个单选：按子文件夹（默认）/ 按文件名，并把跳过的子文件夹
列出来（静默少几个的话，你只会在很久以后发现少了一次测量）。

**★ 「包含所有子目录」那个勾一直是摆设**
api.scan(path, opts) 的第二个参数是**选项对象**，调用处传了个布尔。
`{...true}` 展开之后什么都没剩下，那个勾从来没被发出去过。

**★ 网关返回非 JSON 时报「Expecting value: line 1 column 1」**
resp.json() 没有兜。公司网络上这几乎总是同一件事：代理或 SSO 把请求
截下来回了个登录页，状态码还是 200。那句报错没告诉用户任何能行动的东西。
现在明说「返回的不是 JSON（可能是代理或登录页拦截了请求）」并附上网关原话。
顺带给 test_connection 兜了底 —— 它是排查连不上的唯一工具，自己不能崩。

**填 API 从「粘一段 JSON」改成三个框**
接口地址 / 密钥 / 模型名，填完点「保存并启用」。改地址换模型时密钥可留空
= 不改（界面上只显示打码后的密钥，用户手里未必还有原文）。
密钥框用 password 类型，投屏时不会直接把它投出去。
多 provider 多模型的场景保留粘 JSON，折叠在下面。

**设置页补上缓存占用与清空**
接口早就有，界面上没有。这直接回答「占多少磁盘、能不能清」。
顺带写清楚备份就是拷 workspace/，以及哪些能重算。

**README 重写**：按使用顺序 —— 需要什么、怎么启动、怎么填 API、
数据存哪（含实测占用与备份）、五分钟走一遍、加自己的算法、边界在哪。
原来那份还写着「光学厚度算法尚未接入」，早就接上了。

测试 225 → 232。浏览器实跑验过：全新工作区 → 填三个框 → 抽屉真的能问出话；
导入对话框按子文件夹扫出 3 个样品且 ZG0014 两次分开。
