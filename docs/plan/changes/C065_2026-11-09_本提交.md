## 做了什么
新包 `app/qfls/`（和平台其它部分不共享数据表：结果全在输出目录里的文件里）。

- **`demo.py` 假想数据**（**全部是造的**）：照你描述的结构造 60 个 txt —— 3 个实验（退火温度、钝化剂、衬底）、
  4 个批次、12 种情形（暗斑、划痕、亮点、边缘衰减、倾斜、大尺度不均；100X 故意比 20X 低 24 meV），
  一个实验目录名做成 GBK→cp437 乱码，QFLS 目录里放了历史产物（png、csv、1- 开头的 txt、analysis_* 子目录），
  根目录放了备份说明、别的实验类型（PL 光谱）、临时目录、零散文件；4 帧故意做坏；一个点漏 qvdf、一个点 qvdf 物镜写错。
  默认 304 × 456（真实的 1/4），`--full` 是真实的 1216 × 1824
- **`scan.py` 按层级扫描**：不假设 slot / point 数量；只取 0 开头的 txt；认不出的都列进「跳过」并写原因；只 stat 不打开
- **`names.py`**：三种中文乱码修复（只修显示名）；文件名拆 物镜 / 激光 / 光强 / 时间戳 / uuid（uuid 带横杠，从两头拆；
  时间戳认 14 位数字、带 T / - / _ 的、Unix 秒 / 毫秒）
- **`frame.py` 读帧 + 校验**：BOM、行列一致（逐行数逗号）、空字段 / NaN / 非数字、范围；qvdf 认 JSON / XML / INI，
  一个点用过几个物镜、像素尺寸按物镜分开写都认
- **`metrics.py` 指标**：你列的 15 项全算（另给 P1/P10/P90/P99、最大低值连通域 µm²、变程 µm）；
  连通域用「行程 + 并查集」自己写（没有 scipy），一帧 1216 × 1824 全部指标约 0.3 秒；综合分、ABCD、异常标记
- **`render.py` 出图**：每个样点 热图 / 直方图 / 剖面图 / 异常图 / 变异函数 / 汇总图（前四张拼成 2 × 2）/ 同物镜同色标热图；
  全局 箱线图（6 个指标 × 实验×物镜）/ 排名 / 等级分布。样式照你的 matplotlib 规范
- **`pipeline.py`**：一次处理 = `workspace/qfls/<run_id>/` 一个独立目录（run / scan / points.json / points.csv / summary /
  README.md / global/ / points/<key>/）；组内 z（实验 × 物镜）、平行点离群、尺寸 / 条件和多数不同的标记、全局和物镜内排名
- **接口 `/api/qfls`**：method、scan（只扫描预览）、runs（列 / 开始处理 / 演示数据）、runs/{id}、points、points/{key}、
  files/{path}（只给输出目录里的 png / csv / json / md）、删除；处理走后台任务、逐帧报进度、能停

## 我自行决定的
**影响数值或结论、建议你确认的（10 项）：**
- **D-162**「当前共 60 帧」理解为采集设置（每个 txt 是 60 帧合成的一张图），qvdf 格式不知道 —— **推断**
- **D-165** 校验口径：合理范围 0.3 – 3.0 eV，超范围 > 5% 判无效
- **D-166** 低荧光绝对阈值 1.10 eV；2σ 的 σ 用整帧标准差；边缘带 10%、中心区 50%
- **D-167** 低值连通域先 3 × 3 平滑、8 连通、≥ 5 像素
- **D-168** 划痕候选的 5 个条件
- **D-169** 亮点 = 中位数 + 3σ、3 – 200 像素、按百万像素计密度
- **D-170** Moran's I 在 32 × 48 块均值网格上算（逐像素算永远接近 1）
- **D-171** 变异函数的合并、基台、95% 口径
- **D-172** 综合质量分的七项扣分和 ABCD 分档（**绝对 QFLS 不进分数**）
- **D-173** 异常标记的分级；平行点离群（同 slot 同物镜 ≥ 4 点、稳健 z > 3.5）

其余：D-163 层级识别规则、D-164 乱码只修显示名、D-174 组内 z 与色标、D-175 输出目录与出图、D-176 演示数据的设计、D-177 后台任务。
