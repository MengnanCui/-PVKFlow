## 做了什么

**问题**：平台没有登录，安全边界只靠「只监听 127.0.0.1」。但你开着平台时打开的任何网页也在本机浏览器里，
能朝 127.0.0.1 发「简单请求」（不带 Content-Type 的 POST、multipart 表单），浏览器不会先问。
响应它读不到，但副作用照样发生 —— 包括 `/api/modules/import`，而装模块在**验证这一步就会执行 module.py**。

**改法**：新增 `app/security.py`，作为中间件挂在所有路由之前：

| 闸 | 规则 | 防什么 |
|---|---|---|
| Host | 只认 `127.0.0.1` / `localhost` / `::1`（加上 `HTE_HOST`、`HTE_ALLOWED_HOSTS`），对所有路径生效 | DNS 重绑定：恶意域名改解析到 127.0.0.1 后读本机文件 |
| Origin | `/api/` 下带了 Origin 就必须和本页同源（含端口），`null` 也拒 | 别的网页（包括本机别的端口上的）借你的浏览器调接口 |
| Sec-Fetch-Site | `/api/` 下浏览器标了 `cross-site` / `same-site` 的拒 | 同上，对不带 Origin 的老路径再兜一层 |

页面本身（`/`、静态文件）只查 Host —— 从别的网站点链接打开平台是正常操作。
命令行、脚本、测试不带 Origin 和 Sec-Fetch-*，不受影响。

**界面**：设置页选好 zip 之后、发出任何请求之前，弹确认框说明「module.py 会在你电脑上运行，平台不做隔离，只装信得过的人给的」。点取消不发请求。

**文档**：README「启动」一节和 ARCHITECTURE「安全边界」补上这两条；README 排查表加一行「页面上报『只有平台自己的页面能调用接口』怎么办」。
