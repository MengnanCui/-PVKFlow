## 做了什么

C043 给 CI 的装依赖那一行加了 `--only-binary=:all:`。这一行结尾的 `:` 被 YAML 当成「键:」，
**整个工作流文件解析失败** —— GitHub 一个任务都不跑，只在网页上标红。本机用 PyYAML 复现了同一个错误（第 56 行第 78 列）。

- 修：这一条 `run:` 整个加引号，旁边写了为什么
- 防：`tests/test_launchers.py` 加一条「工作流文件是合法的 YAML、四个任务都在、每一步要么 run 要么 uses」。
  先对坏的文件跑：失败；修好后：通过

## 我自行决定的
- **D-84** 这条测试用 PyYAML，但**不**把 PyYAML 放进 requirements-dev.txt：它还没有 3.15 的预编译包，放进去会让 CI 的 Windows 3.15 任务在装依赖时就失败（D-82 只装预编译包）。
  所以是「装了就查、没装就跳过」—— CI 上它会跳过，真正起作用的是在本机推送之前
