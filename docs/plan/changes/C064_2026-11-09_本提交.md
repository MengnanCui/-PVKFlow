## 做了什么
- `tests/test_agent_power.py::test_the_platform_core_can_never_be_written` 用 `write_text("核心")` 造假的安装目录文件，
  没写编码；Windows + Python 3.11 默认按 cp1252 写，中文写不进去，测试在准备阶段就报 `UnicodeEncodeError`。
  改成 `encoding="utf-8"`（读回来那一句也一样）。
- 只是测试本身的问题，平台代码不受影响（平台读写文件都显式指定编码；Python 3.15 的 Windows 那项默认 UTF-8，所以是绿的）。
