## 当时的说明（原文）

1. 导入记住上次地址，保留最近 3 个（成功扫描后才记，扫不到的路径不占位）
2. 去重加到三条：内容相同(sha256) / 同一个文件 / 同一个子文件夹
   顺带修掉一个静默合并：没给 display_path 时用 src.name 兜底，
   三个样品文件夹里都躺着一个 Data.csv，会被判成同一份 —— 三个样品变一个。
   改成补上父文件夹名，加了回归测试。
3. 强制对齐：figure() 定死三行（标题 / 控件 / 图），没控件的图第二行空着也保留。
   完整报告块也走同一个 figure()。实测四组图的图顶像素级一致。
4. 膜厚不再跟着光谱图的显示数量走：后端拿完整矩阵重算，
   条纹图固定逐帧归一化，跟 ① 的归一化下拉彻底脱钩。
5. 可信度反过来标：全部帧一条淡灰线打底，可信的用绿色点标出来，
   DEGRADED 用琥珀色。原来满屏红点，正确的部分反而看不见。
   门槛从规范默认的 3 条纹改成 2（作为显式 override 传入，DEFAULTS 不动）——
   775–1120 nm 下 3 条纹要求 OT ≈ 3774 nm，真实湿膜大半段到不了，
   拿 3 卡的话整条曲线全判成不准，标注就没有区分度了。
   每一档都配了一句人话解释，文案在后端，前后端不各写一份。
6. 完整报告给全部时刻（211 帧，原来只抽 24 帧）
7. 修模块导航高亮：原来的 IntersectionObserver 观察带在视口顶部 15%，
   最后一个模块永远进不去（页面滚到底就停了），点「特殊处理」高亮留在
   「膜厚处理」上。改成直接算 + 到底强制选最后一个 + 点击时短暂锁定。
8. 全平台铺开术语 ⓘ：新增 web/js/glossary.js（25 条术语，每条都有
   「是什么」和「为什么这么定、代价是什么」）+ components/info.js。
   点开上半截是固定定义（不受模型影响），下半截可以接着问模型。
   每个术语一条独立对话线，历史存后端（conversation.scope_json.topic），
   清了浏览器缓存也还在，抽屉的历史列表里也找得到。

顺带：/api/files/import 接受裸路径列表（原来丢 500）；
richText/inlineText 从抽屉挪进 ui.js，弹窗和抽屉共用一份。

255 个测试通过；浏览器实跑核对了 8 条的每一条。
