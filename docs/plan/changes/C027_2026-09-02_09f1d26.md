## 当时的说明（原文）

你提的第 1 条。先说清一件事：**地址栏本来就是自由文本框，后端也一直收
`http://`**（`app/api/settings.py` 里明确放了 http 和 https 两种）。
所以「输不进去」不是输入框的问题 —— 真正缺的是你说的后半句「加入默认」：
候选清单硬编码在 `openai_compat.py` 里那六条，你没有任何办法把自己的网关
加进那个下拉，每次配都得重新贴一遍地址。

现在下拉里那份 = **自己存的（排最前，带★）+ 内置的公共网关**。
地址栏旁边一个「存成候选」按钮，填一次以后直接选；已经存了的那条按钮变成
「从候选里移除」。自己那份存在 `workspace/config/providers.json` 的
`presets` 里 —— 和密钥同一个文件、同一条 .gitignore，**内网地址不进仓库**，
仓库里那份 PRESETS 仍然只有公共网关（`test_presets_never_contain_a_private_gateway`
继续盯着）。存 provider 时连同 providers 之外的顶层键一起写回，
否则保存一次模型就会把候选清单一并抹掉。

顺带一条你没提但同样卡人的：原来**必须先选中至少一个模型才让保存**。
自建网关很多不实现 `/models`，拉不到列表就卡在这儿，地址想先存下来都不行。
现在「模型列表留空 = 不改」，和密钥同一条规则：第一次配就存成空列表
（界面明说「还没有模型，手填一个再保存才能开始对话」），
改地址时留空则保留已经存着的那些，不会被悄悄清掉。

**没改的**：discover 的报错分级已经是好的 —— 连不上 / 401 密钥被拒 /
404 网关没实现 /models / 返回的不是 JSON（代理或登录页拦截），
每一种都有自己那句话。我本来打算改，读完发现没什么可加的。

验证：新起一个 http 的假网关，走完保存 → 拉列表 → 真发一次请求三步
（`test_a_plain_http_gateway_works_end_to_end`），密钥确实带上了 Bearer、
返回里一个字段都不带密钥。339 项 pytest（新增 3 条）。

另外修一个顺带发现的：`toast(..., 'danger')` 有四处在用，
但 CSS 里只有 `toast-ok/err/info` —— 那四个错误提示弹出来是没有小圆点的。
补上 `toast-danger` 和 `toast-warn`。
