## 当时的说明（原文）

Windows 上双击 run.bat 就能打开、导入、处理、存结果的本地应用。
这一期做的是架子和契约，不是功能堆料。

Skill 契约（核心交付）
  spec.params 自动渲染成参数表单，spec.outputs 自动渲染成结果卡片，
  返回的 ChartSpec 自动画成图 —— 加一个 skill 不用碰任何前端代码。
  两条接入通道：Python 插件（主通道）和 SKILL.md（模型通道）。
  推荐打分对"声明了特征却没命中"扣分，否则吃 .csv 的 skill 会挤在同一个
  分数上，排序等于没有。
  膜厚 / 光谱留成只需填一个 analyze() 的模板，在算法接入前诚实标注
  "待接入"并拒绝运行，不假装跑通。

存储
  文本类按 sha256 内容寻址复制进工作区（自动去重），图像只登记路径 +
  缩略图不搬动原图；断链标 missing，不静默失败。
  key_result 用长表，新增测量字段零 schema 变更，构效关系页后期直接透视。
  每条结果带 source / quality / version，一年后还能说清这个数怎么来的。
  大量数值走 Parquet，pyarrow 异常时降级 CSV 也不丢数据。

AI 层
  OpenAI 兼容多 provider，按 providers.json 配置。
  没配模型时文件识别、skill 推荐、数据检查全部走确定性规则引擎，照常可用；
  界面标注每条结论来自"规则"还是具体模型名，不制造假的智能感。
  密钥只写 workspace/config/（已 gitignore），接口返回一律打码。

界面
  零构建的原生 ES Module，配色对齐 matplotlib 出图规范。
  去掉了原型里的装饰性实体：渐变、星标、大写字距标签、虚构数字、
  满屏 chip。正文字号从 8-10px 提到 13.5px，指标一律 tabular-nums。
  空态、加载态、错误态都有交代。

62 个测试覆盖分类落地、去重、断链、命名解析、skill 打分与落库、
无模型时的规则兜底、API 错误结构。
