## 做了什么
- **批处理只有一条路**：AI 卡片发起的批处理（数据处理页的确认框）提交后也落到对比页、在那里看进度 ——
  原来它留在数据处理页自己轮询，和手点的「直接对比」两条路两套进度条。删掉 `progressBlock / startPolling / S.task / S.pollTimer` 约 80 行
- **下钻页回你来的地方**：样品、批处理结果、QFLS 样点三页的「返回」由 `app.js` 统一放在页头右上角第一个，
  写的是要回去的那一页的名字（「← 构效关系」「← 对比历史」）。从哪来回哪 —— 原来样品页固定回数据处理，从构效关系、存储页、
  对比页点进来的也被送回数据处理；三页的返回按钮一个在页头、一个在内容区。直接打开链接 / 刷新时回页面声明的父页。
  侧栏高亮跟着来处走（从构效关系点进样品，亮的是构效关系）
- **该点得进去的都点得进去**：总览「最近的处理」一行点进那次对比（单独跑的点进样品）；批处理结果页的运行状态表、失败表，一行点进那个样品。
  都能用键盘（Tab 到行上回车 / 空格），点进去之后「返回」回到这一页
- **对比历史能改名、能删**：每行右边「改名」「删除」。删之前先给你看会带走什么（几个样品、几条关键结果 —— 其中几条现在是样品的当前值、几条审核过、
  几张曲线表、几条钉住的 AI 分析），确认了才删。后端 `app/batch_history.py`，接口 `PATCH / DELETE /api/batch/runs/{id}`、`GET …/footprint`
- **地址栏**：任务跑完后 `#batch/task_…` 换成 `#batch/run_…`（不多一条后退记录）—— 原来收藏、刷新、发给别人都要再等一遍任务
- AI：对话的范围里记着一次已经删掉的对比时，事实包里说「你问的那次已经删了，下面是最近一次」，不再冒充「你正在看的这次对比」
