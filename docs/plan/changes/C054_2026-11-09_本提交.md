## 做了什么

### D-1 结果质量审核（可信 / 待查 / 作废）
- **后端**：`results.set_quality` 记下理由（≤ 500 字）和时间，返回这条结果和**审核之后的当前值**；
  新增一次审几条（`POST /api/results/quality`，一条不存在就一条都不改）和「一个样品的全部结果」
  （`GET /api/results/by-sample/{id}`：每个字段的当前值 + 历史）。数据库迁移第 4 步加两列 `quality_note`、`quality_at`（先备份）
- **样品页**最后一节「关键结果」：每个字段一行 —— 当前值、来自哪次处理、谁审过 / 什么时候、审核按钮；
  「历史 N 次」展开每一次算出来的数，每条都能单独审。作废了最新的，当前值退回上一次，表上和提示里都说退回到了哪个数。
  「最近一次处理」的结果可以一键全部可信 / 全部作废（一次测量坏了的情况）
- **构效关系页**：逐个样品的表里 X、Y 各一组审核按钮；箱线图的离群点旁边也有。作废一个，这个点就从图上拿掉，
  统计跟着变；刷新时不闪占位、表格保持展开
- 「可信」分得清是**程序给的**还是**人审过的**：批处理写进去时就是「可信」（原有行为，见 D-115），人点过才有审核时间

### D-2 断链巡检
- `verify_references` 现在也查复制进工作区的文件，并且说出**是哪些**：文件名、记录的位置、属于哪个样品、是不是这次新发现的；
  放回去再查会标回正常、报「找回来几个」。状态改动一次事务写完（原来一条一个事务）
- **存储页**新一节「原始文件还在不在」+「检查一遍」按钮；**总览**上「有 N 个文件找不到」的提醒加了「去看是哪些」

### D-3 样品集管理
- 数据处理页左栏「样品集」旁边多一个「管理」：改名（回车也行）、动态集「钉死」成固定集、删除。钉死和删除都先确认，
  写明「只删样品集，样品和结果都不动」「钉死不能撤回」
- 后端补的边界：改名撞名原来是数据库唯一约束直接 500 → 现在 400 说「已经有叫…的了」；改 / 删一个不存在的原来默默成功 → 404；
  一个样品都不命中时不让钉死（会钉出一个永远空的固定集）

### 自查发现：确认框点「确定」永远返回「取消」
`ui.confirmDialog` 的「确定」按钮先 `m.close()` 再 `resolve(true)`，而 `close()` 里会先跑 `onClose → resolve(false)`，
Promise 只认第一次。所以**从第一版起，凡是走确认框的操作点了「确定」都没有反应**：
- 设置页**装模块前**的「我信得过，继续」（S 组 / P-43 加的那一步）—— 也就是从界面上装模块一直装不上
- AI 抽屉里**删除对话**
- 设置页**卸载模块**

之前的验收只在接口层测了这几件事，没在浏览器里点过确认框，所以没抓到。改成「答案只在关闭时交出去一次」。
顺带：弹窗里再弹确认框时，原来按一下 Esc 两层一起关（两个都在 document 上听键盘）—— 现在只有最上面那层响应 Esc / Tab。
