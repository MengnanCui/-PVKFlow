## 当时的说明（原文）

1 / 2.1 / 3　功能区左右不一致 —— 上一轮没修干净，一个根因
  subgrid 统一的是**行高**，但三个子块都 align-self:start，
  于是盒子自己缩到内容高度：左格 92px、右格 43px，底下空 49px。
  图是齐的，两个带边框的面板一高一低 —— 那就是你看到的「不一致」。
  修：.figure-ctl 在 subgrid 行里 stretch。实测三个模块每一行都等高。
  另外把「窗口分辨率」那段说明从功能块移到图下面 —— 它是说明不是控件，
  放进去把那一格撑到 166px，同排另一格只有 43px。

2.2　波段无法打字
  oninput 里逐键钳位并回写输入框：想输 800，敲下 `8` 的瞬间被钳成 330。
  改成 oninput 只解析（绝不回写正在打字的那个框），change/blur 才归一。
  顺带修了 change+blur 连着触发导致一次输入打两次后端。

2.3　滑动和默认数字不一致
  <input type=range min=330.276 step=1> 的合法值是 min+n×step，
  value=775 被吸附到 775.276 —— 数字框写 775，滑块在 775.276，一碰就跳。
  step≥1 时把边界取整，数字框和滑块用同一套边界。

2.4　DEGRADED / LOW_CYCLES / OK 的解释
  从图注下面那三行移进 ot_status 的 ⓘ 里，并且带上「这张图里 N 帧」。

2.5　ⓘ 不许遮挡整个页面
  从全屏 modal 改成贴着按钮的浮层：没有遮罩，页面照常看得见、滚得动；
  上下翻转、左右夹在视口内、滚动时跟随、点外面或再点一次收起。

4.1　选中多个样品直接进对比页
  原来先弹一个填六个数的对话框 —— 那时候你还没看到任何结果，
  六个数该填什么无从判断。现在直接用默认配方开跑、直接落到对比页
  （页面自己显示进度），参数摆在页面顶部，改完「按新参数重跑」是新的一次对比，
  旧的留在对比历史里。

4.2　不同时刻的平均膜厚
  批处理原来根本不算膜厚（长表只有 integral / slope）。现在逐帧算，
  走的是单样品页**同一个** fringe_ot.extract_series —— 有测试钉住
  两边逐点一致，免得哪天有人抄第二遍。膜厚单独一张表：它的时间轴是全部帧，
  另外两条可能被 max_time_points 抽稀过。
  新接口 /runs/{id}/slices?windows=0:1,27.5:28.5：
  - 窗口内**全部帧**都参与平均，另给可信比例（你定的口径）
  - 窗口超出该样品时间范围时返回 null 并说明，**绝不拿最近一帧顶替**
  - 这是查询不是配方 —— 加减时间窗不用重跑，只有改波长窗口才要
  前端：新增分组柱状图（深色那截 = 可信比例，没数据的位置画「—」不画 0 高柱），
  样品超过 24 个降级成排序表格并说明原因。膜厚曲线也进了对比页。

5　模型配置能点着填
  - 地址：填过一次就一直回填（存本机 gitignore 的配置），
    外加几个**公共**服务商预设。内网地址一如既往不进仓库，有测试盯着。
  - 新接口 /models/discover：按 OpenAI 兼容协议拉 /models，不用手打模型名。
    密钥留空 = 沿用已存的；返回里一个字段都不带密钥。
    拉不到不是死路 —— 不少网关没实现 /models，错误里直接说「手填一样能用」。
    代理/SSO 回登录页时说清楚是这件事，不是丢一个「Expecting value」。
  - 一次可存多个模型；连接测试打通
  - 抽屉和 ⓘ 小窗都能切模型，共用同一个选择；换模型时在对话流里插一行提示
    （后端本来就收 provider/model，缺的只是能选的地方）

267 个测试通过（新增 12 条）；明暗两套主题浏览器实跑，5 条逐条核对。
