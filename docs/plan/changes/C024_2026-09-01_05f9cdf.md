## 当时的说明（原文）

── 样品列表塌掉（每天都会遇到，不是小屏才有）
一行 7 列里 5 列是固定宽，加上间距要 468px。容器不够时两个 fr 列被压到 0：
样品名变成「Z…」，表头「光谱矩阵」竖排成四个字，「全选本页」竖成四行。
**打开 AI 抽屉就会触发** —— 1440 屏上主区只剩 860px。视口断点管不了它，
抽屉不改变视口宽度，所以用容器查询：700 / 560 / 430 三档依次让
「光谱矩阵」「大小」「测量时间」下岗，名字和样品号留到最后。
不支持容器查询的浏览器忽略这几条，退回今天的行为，不会更糟。

── 灰阶对比度（这一条改了色值，你单独批准过）
深色过一遍时把两套主题实测了，结果和预期相反：**亮色才是差的那个**。
--ink-4（.dim，用在图注、字段说明、指标副文）亮色下只有 1.79:1，
深色 2.50:1 —— 正文小字的线是 4.5:1，连非文本的 3.0 都没到。
而它承载的是「8 条 · 0.00–21.08 s · 422–1121 nm · 颜色由浅到深 = 由早到晚」
这类真信息，不是装饰。

没有把两级都压到刚过线 —— 那样它们会变成同一个颜色（#6c6c72 / #6c6c6f），
四级灰阶塌成三级。按梯度解，ink-2 不动：
  亮 --ink-3 #8b8b93 → #5e5e63   最差 2.94 → 5.61
  亮 --ink-4 #b4b4ba → #6c6c6f   最差 1.79 → 4.55
  深 --ink-3 #83827f → #999894   最差 4.42 → 5.88
  深 --ink-4 #5c5b59 → #868481   最差 2.50 → 4.55
（按同主题四层背景里**最难**的那层算。）强调色、12 色序列色、语义色一个没碰。
顺带量到亮色 --warn 是 4.10 也差一点，但它是图表里定了稿的语义色，
不在批准范围内，只把实测值写进注释备查。

── 顺带
· 删掉 layout.css 里 16 行死 CSS：.workbench 三栏（含一个 max-width:1360px
  断点）JS 里一处都没用，数据处理页走的是 .select-layout。留着会让下次
  调小屏的人对着一个不生效的断点改半天。
· 热力图右边距 96 → 78。96 是在 900 单位的 viewBox 里定的，那时被 0.59 倍
  缩放、落到屏幕上只有 57px；坐标系换成真实像素后照抄等于凭空放大七成。
· 弹窗右上角「关闭」文字钮 → × 图标钮（底部本来就有一个「关闭」按钮，
  两个同名的看起来像有两种关闭方式）。
· 骨架屏从三根随机宽度的细灰条换成「标题条 + 内容块」，空态给了正经版式。

验证：五档屏宽（1280/1361/1366/1440/1500）无溢出无压没；四级灰在两套主题
四层背景下全部 ≥ 4.5:1 且梯度未塌；图表刻度仍是 11px（scale 1.00）；
拖动 3.9/4.1 ms、悬停 0.1–0.2 ms / 5–11 节点，都在原区间；
图表 18 项 / 热力图 11 项 / 换参数 8 项 / 动画 8 项 / 焦点 174 项全过；
330 项 pytest 全绿。对比页四种状态第一次拍了截图。
