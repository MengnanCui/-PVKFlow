## 做了什么
- **共用组件只留一份**（`web/js/ui.js`、`components/field-cells.js`、`components/figure.js`）：
  - 指标卡 `metric()` / `metricRow()`：总览、存储、批处理结果、QFLS 原来各抄一份
  - 字段表 `fieldTable(fields, {numeric})`：总览、存储、构效关系原来三份、列也不一样（构效关系那份把最小最大挤成一格、条数用的是另一个数）
  - 下拉：批处理结果页的 `batch-state.select` 和 `figure.selectControl` 逐字相同，删掉前者
  - 分段控件 `segmented()`：智能体页的 `seg()` 和 QFLS 抄的那份 CSS 合成一个，**支持方向键**
    （Tab 进来落在选中的那个上，←→ / ↑↓ 换、Home / End 到头尾，和单选按钮组的读屏约定一样）。CSS 类 `.agent-seg` 改名 `.seg`
- **离开页面真的中止请求**：`api.with(signal)` 给出同一套接口，这次发的请求都挂在页面的 signal 上 ——
  原来只能等请求回来再丢掉，大批处理的曲线照样下载完。总览、存储、对比历史、批处理结果页（详情、曲线、切片、钉住）已经接上；
  中止抛 AbortError，`ui.render` 和各页的 `alive()` 都按「过期」处理、不显示成报错。`get / post` 本身也收 `{signal}`
- **设置页不靠全局事件**：原来存完东西靠 `window` 上的 `hte:nav` 事件让设置页重画自己；现在用进入页面时给的 `ctx.nav / alive`，
  「离开了就不重画」由 `alive()` 判断（原来要看地址栏）。`app.js` 里那个全局事件监听删掉了
- **智能体页**：报错用 `errorBox`（和别的页面同一个红框，带详情）而不是黄色提醒框；「没配模型」那条照旧是提醒（它是引导，不是错）。
  本地的 `busy(on)` 改名 `setRunning(on)` —— 和 `ui.busy(按钮, 开关)` 重名、意思又不一样
- **长行**：一百一十几行超过 140 个字符，拆开（只换行，不改逻辑和文字）。清单里原来写「老页面没有」不对 —— 老页面也有十几行，一起拆了。
  `glossary.js` 例外：术语表正文一条定义一行，拆开反而难和审稿清单对照
- 测试守着（`tests/test_frontend_style.py`）：超过 140 个字符的行、页面里又抄一份指标卡 / 分段控件 / 下拉，都会挂
