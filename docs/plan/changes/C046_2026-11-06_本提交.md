## 为什么被标成失败，怎么修

收尾时 `Stop-Process` 已经把服务连同 cmd 一起拔掉，紧接着的 `taskkill` 找不到进程，返回非零。
GitHub Actions 的 PowerShell 外壳拿「最后一个外部命令的退出码」当这一步的结果 —— 所以全部通过之后还是红的。
修法：`finally` 末尾把 `$LASTEXITCODE` 清零。真出错时 `try` 里的 `throw` 照样让这一步失败，不受影响。

这是 CI 脚本的问题，不是 run.bat 的问题。
