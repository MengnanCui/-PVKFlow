## 做了什么

### 后端
- **`app/analysis/stats.py`**：皮尔逊 r（p 值、95% 置信区间）、斯皮尔曼 ρ（p 值）、最小二乘直线、箱线图统计。
  **不装 scipy**（装机体积一直盯着）：p 值用 t 分布，t 分布的尾概率用正则化不完全 β 函数自己算。
  在另一个装了 scipy 1.18.1 的环境里算了 7 组数据的参考值（含并列名次、负相关、n = 3、n = 300、p 小到 10⁻⁷⁶），
  **逐个对上，最大相对误差 7×10⁻¹³**；参考值原样抄进了测试
- **`app/storage/relation.py` + `/api/relation/pairs`、`/groups`**：把关键结果「当前值」按字段透视成每个样品一行
  （同一个样品跑过三次批处理，图上也只有一个点）。**样品范围就是数据处理页的筛选式**：那一页筛出什么，这里就分析什么。
  只有一个字段有值的样品不进图，但会数出来告诉你
- 样品少（< 3）、或者某一列所有样品都一样时，**不给数，说为什么**

### 前端（构效关系页重写）
- **散点图**：每个样品一个点、按批次着色、虚线是最小二乘直线。指到点上看是哪个样品，点一下打开它。
  X / Y 任选、一键交换；范围可选「全部 / 数据处理页筛出的 / 数据处理页勾选的」
- **统计**：样品数（以及多少个只有一边的数）、皮尔逊 r + 95% 置信区间 + p、斯皮尔曼 ρ + p；
  样品少于 10 个时说明斯皮尔曼的 p 是近似值；**字段在不同样品上单位不一致时警告「这里的相关不可信」**；
  一段人话说明 r / ρ / p 各是什么，以及「相关不等于因果」
- **按批次的箱线图**：任选字段；离群的样品画成单独的点，悬停有名字、点了打开，下面也列出来
- **逐个样品的表**（键盘也能打开样品）、**下载**：图片，和数据（每个样品一行，带样品名和批次，过 CSV 公式防护）
- 页面底部写明还没做的：异常识别、让模型写总结

### 图（D-105 说的整理 `xyChart`）
散点图和箱线图是新写的（`components/relation-charts.js`）—— `xyChart` 是画曲线的：悬停按 X 找最近、只缩放 X、
点多了会抽稀（每条最多 180 个点），一个点就是一个样品时这三样都不对。
三种图的网格、坐标轴、刻度、轴标题抽成 `chart.drawGrid / drawAxes` 共用，`xyChart` 从约 440 行降到 388 行，画出来的东西不变。
