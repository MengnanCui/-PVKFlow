## 做了什么
- **侧栏「分析 → QFLS 成像」**（`web/js/pages/qfls.js` + `qfls-state.js` / `qfls-views.js` / `qfls-method.js` / `qfls-point.js`）
  - 顶栏：选看哪次处理、**处理新数据…**（浏览本机目录 → 扫描预览：认出几个实验 / 几帧、修过的乱码名、跳过了什么和为什么 → 开始处理）、
    **生成演示数据**、下载全部样点 CSV / README、删除这次处理（只删输出目录）；处理时显示进度、能停，刷新页面后接着显示
  - 筛选条：实验、物镜、等级（含「无效」）、每种异常类型、只看异常、搜编号；「筛出 n / N」；**导出当前筛选**
  - **总览**：四个数；等级分布表（实验 × 物镜，点一行只看这一组）；任选指标的**箱线图，按物镜分开画**（随筛选变，点离群点进详情）；
    扫描报告（编号对照、乱码目录原名、跳过清单、历史产物举例）；服务端出的三张全局图
  - **排名与筛选**：全部指标一张表，点表头排序，原值 / 组内 z 切换；**异常整行标色**，异常标签悬停看原因；勾选加入对比
  - **单点详情**（`#qfls-point/<处理>/<样点>`）：身份和采集条件、全部异常、5 张图（热图、异常图、直方图、剖面、变异函数）+ 汇总图、
    **综合分逐项扣了多少**、全部指标（值、组均值、组内 z、能否跨物镜比）、划痕候选明细、qvdf 元数据；上一个 / 下一个走当前筛选的顺序
  - **多点对比**（2 – 6 个）：物镜不同时提示哪些数不能横着比；同物镜同色标热图（带色标条）；直方图 / 剖面 / 变异函数叠加；指标对照（最好的加粗）
  - **方法说明**：数据怎么认、怎么校验、每个指标的算法、扣分表、等级、异常、分组标准化、你给的限制、演示数据声明 —— 数字直接读这次处理的参数
  - 每个标签顶上常驻「不同物镜不可直接比较 / 单光强不做 JV」
- **自查修的老问题（`web/js/chart.js` 的 `trackWidth`）**：同一轮代码里先造几张图、最后一起挂进页面时，先造的那张的宽度观察者
  会被后造的那张当成「已离开页面」断掉，宽度永远停在兜底的 760 像素（QFLS 总览的第二张箱线图因此被挤到滚动区外面看不见）。
  查下去对比页的切片图也一直有这个问题（批处理页 5 张图里有 2 张不跟着窗口宽度走）。现在：刚造的不算（这一轮跑完还没进页面的才算丢掉），
  从页面上拿掉的由观察者自己当场断开 —— 不再越挂越多，也不会误断
- 色标口径（D-174 → D-181）：同物镜色标从「P1 / P99 的中位数」改成「P1 的第 5 百分位到 P99 的第 95 百分位」—— 原来最好的几帧整片饱和
- 文档：README 加「7. QFLS 成像」；ARCHITECTURE 加 `app/qfls/`；tools/qa/README 加 `qfls_check.js`
