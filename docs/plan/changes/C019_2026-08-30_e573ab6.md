## 当时的说明（原文）

## 起因

你想让同事往平台里加功能，但担心风格会漂、GitHub 用不了、他们只有弱模型。
挖下去发现：**后端的插件机制你第 3 个任务就建好了**（app/skills/，
放个文件夹点一下重载就生效），只是你自己的旗舰功能全都绕过了它 ——
sample.js 是 1000 行手写页面，process.js 的功能 tab 是写死的数组。
所以同事看到的示范是「手写一个大页面 + 改三处平台代码」。

这次补的是交互式面板那一层，并且**拿平台自己的功能验证它是真的**。

## 契约

一个模块 = workspace/modules/<名字>/module.py 一个文件。
同事写声明（有哪些控件、哪些面板、产出什么）+ 可选的算法。
平台写：面板结构、控件、图注、下载菜单、ⓘ、左右对齐、批处理接入。

**他不写 HTML/CSS/JS，也碰不到它们** —— 风格不是靠自觉，是靠他没有
画界面的机会。

## 「拖动即时响应」没有丢

这是你明确说不接受的代价。答案在已有代码里：bandIntegral / wavelengthSlope
本来就是双实现（web/js/spectra.js 一份 JS，app/parsers/render.py 一份
Python），连注释里的理由都是同一句。给它一个名字、封闭成算子集、
加一条一致性测试，模块就白拿了这个能力。

A 档：面板用平台算子拼（live=Op.xxx），拖控件时在浏览器里跑，实测 2.2 ms
B 档：算子拼不出来的写普通 Python，松手才算 —— 这就是膜厚模块现在的行为

tests/test_ops.py 是承重墙：拿同一个矩阵跑 Python 和 node，断言逐点相同
（容差 1e-9），并检查两边算子名完全一致。少了它，症状是「界面上拖出来
一个数、存进库里是另一个数，而且没有任何报错」。
验证过它真能抓错：把 JS 的梯形法改成矩形法 → 红；从 JS 删一个算子 → 红。

## 迁移「特殊处理」——契约的活示范

app/modules/builtin/special_processing/module.py，**一行算法都没有**，
两个面板都是算子拼的。有测试钉住它和旧 render.* 逐点一致。

延迟：迁移前 2.2 ms → 迁移后 2.2 ms。中间一度掉到 3.4 ms，原因是
paintLocal 把所有面板都重算了（旧代码只重算被拖的那一格），改成只重算
真正依赖该控件的面板就回来了 —— 不是「差不多」，是找到并修掉了那 1.2 ms。

## 验证器 = 给弱模型的反馈通道

装之前先跑，不通过装不上。每条报错点名字段、说清错在哪、列出合法值、
还会猜打错的那个词：

  ✗ panel "integ" 的 uses 里写了 "integral"，但 controls 里没有这个 key。
    现有的 controls：slope_center, slope_half, integ　你是不是想写 "integ"？

「报错 → 贴给模型 → 改 → 再试」这个循环设计出来就是给弱模型用的。

## 分发不靠 Git

一个模块 = 一个文件夹 = 一个 zip。设置页导入/导出，企业微信发过去就行。
装失败的模块会显示出来并说清原因，不静默消失；一个坏模块不会弄死平台，
也不会带走整批批处理（会说清是哪个模块崩的）。

## 批处理自动接入

模块声明 batch_curves，平台就把它接进长表、对比页叠图、时刻切片、导出脚本
—— app/batch.py 里写死的 integral/slope 换成了模块驱动。同事加一个模块，
这些地方一处都不用改。

## 顺手修的两个真 bug（都是平台原有的）

* numberControl 的 range：h() 按对象顺序设属性，value 排在 max 前面，
  赋值那一刻 max 还是默认的 100 —— 950 当场被夹成 100。症状是数字框写 950、
  滑块停在最左边。上一轮修 bandControl 时漏了这个。
* 同一个控件的 min+n×step 吸附问题（950 → 950.276），也一并修了。

## 交付物

docs/MODULE_AUTHORING.md（写给模型看）· app/modules/_template/（自己能过验证，
有测试钉住）· 迁移后的特殊处理作为活示范

302 个测试通过（新增 41 条）；浏览器实跑：造了一个「同事写的」模块
（A 档 + B 档混用）打包成 zip 导入，它出现在导航里，和平台自己的模块
长得一模一样、等高对齐、图注一致。

## 这一部分没做

* 光谱处理和膜厚处理没迁（耦合深，等契约在真实使用里站住再说）
* process.js 的功能 tab 仍是写死的：那三个 ready:false 是**数据类型**
  （荧光、散射），模块目前只吃 spectra_matrix，改成动态会暗示一个
  不存在的能力
* 算子集只有两个，不预先扩充
* 没有沙箱：模块是 Python，能跑任意代码。装谁的模块就是信任谁，
  文档里写明白了，不假装有安全边界
