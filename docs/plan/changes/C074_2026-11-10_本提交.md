## 做了什么
**路由只剩「收参数 → 调领域函数 → 回结果」**，业务逻辑搬到领域层（命令行、测试、以后别的入口不用经过 HTTP 就能调）：

| 原来在 | 现在在 | 内容 |
|---|---|---|
| `api/batch.py` | `app/batch_views.py`（新） | 批处理结果详情、曲线读取、时间窗切片统计、导出包 / 预览 |
| `api/modules.py` | `app/modules/install.py`（新） | 模块 zip 的大小闸、解压、暂存、验证、升级判定、导出、卸载 |
| `api/chat.py` | `app/ai/assistant.py`（新） | AI 抽屉的系统提示、术语解释提示、动作卡片解析 |
| `api/results.py`、`files.py`、`spectra.py` 里的 SQL | `app/storage/catalog.py`（新） | 最近文件、样品列表、存储统计、文件筛选项、有矩阵的样品 |
| `api/spectra.py` 的 `_resolve / _load` | `app/storage/artifacts.py` | `resolve_matrix_id`、`load_matrix` |
| `api/qfls.py` 读单点 | `app/qfls/pipeline.load_point` | |

- **路由之间不再互相 import 私有函数**：流式响应的 `_frame / _resolve_or_501 / _ClosingStream` 抽成 `app/api/streaming.py`，AI 抽屉和智能体共用；
  模块计算原来借 `spectra._load`，现在直接调 `artifacts.load_matrix`；模块计算只取请求的面板改成 `ModuleContext.only()`
- 领域层抛 `NotFound` / `Invalid`（都带 `kind`，接口回 404 / 400 时原样带出），不再 import `app.api`、不再抛 `ApiError`；
  `registry._load_one` 改名 `load_file`（模块验证、命令行检查都在用，不算私有）
- **批处理计算线程不碰数据库**：文件位置在主线程里先找好（找不到时会把文件标 missing —— 那是写库）；找不到的直接记失败、不进线程池。
  **落库出错时**（磁盘满、库被锁）撤掉还没开始的样品、马上报错 —— 原来线程池退出时要等剩下的全部算完才报
- **上限**：上传单个文件 512 MB（超过回 413，边读边数，不先读进内存）；「批量标质量」一次最多 500 条、重复的 id 只算一次
- **任务中断收尾钩子**：`tasks.register(kind, on_interrupted=fn)`。重启时 `tasks.reap_interrupted()` 把没跑完的任务标失败，
  再按任务种类调各自的收尾 —— 批处理收它建的分析运行，QFLS 收它那次处理的 run.json（只收那一次，不再扫整个输出目录）。
  原来两份收尾一份写在任务队列里、一份写在 `main.py` 里直接调，各管各的；一种任务收尾出错不会挡住别的（记日志）
- **QFLS 分数完全由 `PARAMS["score"]` 驱动**：每一项扣分写明看哪个指标（`metric`）、要不要先取绝对值（`abs`）、怎么显示（`label` / `unit`），
  `score()` 逐项照算 —— 加一项扣分只改参数表。全局箱线图画哪几个指标列在 `metrics.BOX_FIGURE`（参考线取自参数，不再写死 0.15）。
  方法说明页的扣分表照 `params.score` 逐行列出（早期 run.json 里没有 `metric` 的按原来七项补上）。
  **分数一个数都没变**：新旧 `score()` 在 2000 组随机指标上逐项相同

## 我自行决定的
- **D-190** 上传单个文件上限 512 MB，超过回 413「too_big」（一个原位矩阵通常几十 MB）
- **D-191** 「批量标质量」一次最多 500 条，超过回 400；重复的 id 去重后再算
- **D-192** 批处理：找不到文件的样品在主线程里先记失败、不进计算线程；落库出错时撤掉剩下没开始的样品、立即报错（已经写进去的保留）
- **D-193** QFLS 扣分表里的 `metric / label / unit / abs` 是口径，处理时不能覆盖（只能改数字，改口径回 400「是口径」）
- **D-194** 任务中断收尾由各任务注册的 `on_interrupted` 做；批处理的收尾把所有「运行中」的分析运行标失败（只有批处理建分析运行，所以整表扫）

都不影响任何数值或科学结论。
