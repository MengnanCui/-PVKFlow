## 做了什么

### 权限整理（P-51）
- **写只在专用目录 `workspace/agent/`**：智能体写的脚本、报告、中间数据都在这儿，跑命令也在这儿跑。工作区其余部分改成**只读**
  （原来工作区整体可写、只挡几个子目录）。你另外加的文件夹照旧单独选只读 / 读写
- **平台核心（安装目录里、工作区以外：app/、web/、run.bat……）任何时候都不能写**：不能加成可写文件夹；
  就算设置被手改成可写也不认；写文件时按真实路径再核一次。读可以（让它看代码没问题）
- 写错时的报错直接告诉模型该写哪儿（「智能体只能写在专用目录 agent/ 里，比如 agent/notes.md」）

### 跑命令（P-52，`app/agent/commands.py`）
- `run_command`：在专用目录里跑（Windows 是 cmd，其它是 sh）；`python` 就是平台那套（有 numpy / pandas），
  所以「写脚本到 agent/ → 跑」直接能用；超时默认 60 秒、最多 600；**超时和停止都杀掉整棵进程树**；输出打码、太长留头尾
- **危险命令每次都问**（自动模式也问、记不住）：rm -r/-f、del /s、format、shutdown、curl | sh、git push、pip install、碰数据库 / 密钥文件……
- **核心守卫**：每条命令前后给平台核心拍快照，有文件被改 / 加 / 删就写进结果、让模型停下来告诉你
- ⚙ 里能关掉跑命令（关了模型连这个工具都看不到）

### 常用 agent 功能（P-53）
- **询问 / 自动**：会改东西的操作（写文件、跑命令、跑批处理、审核……）每次问，还是直接做。删除和危险命令两种模式下都问
- **直接执行 / 先出计划**：先出计划时只给只读工具 + `propose_plan`；模型要动手一律退回；交了计划这一轮结束。
  计划卡上「按计划执行」把计划放进提示里去执行（会改东西的照样按权限问），「改一改」把步骤填回输入框
- `/undo`：撤销这个会话里智能体改过的全部文件

### 轻量对话窗口（P-53）
- **一栏到底**：顶上一条细栏（会话下拉、＋、询问 / 自动、直接执行 / 先出计划、模型、⚙），中间对话，底下输入框和一行状态
  （「写：workspace/agent/ · 跑命令：开 · 权限：询问 · 模式：直接执行」）
- 每次调工具一行：▸ 工具名 · **关键参数**（命令本身、文件路径……）· ✓ 用时，点开看参数和原文
- **斜杠命令**：/plan /exec /ask /auto /new /undo /stop /help
- 权限一览、文件夹、跑命令开关、调用方式、工具清单收进 ⚙ 抽屉

## 遗留 / 没做的
- **跑命令不是沙箱**：核心守卫只能事后发现。要真隔离得用容器 / 单独的系统用户，那是另一件事
- 命令不能交互（stdin 是空的）；长时间跑的服务（比如起一个 web 服务）会被超时杀掉
- 计划没有「编辑后再批准」的结构化编辑器，「改一改」是把步骤填回输入框让模型重出
- 没在你的真实网关上试过
