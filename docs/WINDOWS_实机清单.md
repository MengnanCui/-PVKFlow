# Windows 实机检查清单

CI 已经在 GitHub 的 Windows 机器上跑过 `run.bat`（建虚拟环境 → 装依赖 → 起服务 → 首页能打开），
也在 Windows 上跑了全部测试。但那是一台干净的、英文系统、联网通畅的机器。
你和同事的电脑是**中文系统、公司网络、可能装过别的 Python** —— 下面这些只有在真机上才看得出来。

**谁来做**：你或任何一位同事，一台平时用的 Windows 电脑。约 10 分钟。
**做完发回来**：每一步的「结果」那一栏，以及出问题时窗口里的文字截图。

| # | 做什么 | 应该看到 | 结果 |
|---|---|---|---|
| 1 | 把整个项目文件夹放到一个**带中文、带空格**的路径下（例如 `D:\实验 数据\PVKFlow`），双击 `run.bat` | 黑窗口里依次出现 [1/3] [2/3] [3/3]，中文不是乱码；约 1 分钟后浏览器自动打开 | |
| 2 | 看窗口里打印的地址 | `http://127.0.0.1:8765`（端口被占时是 8766、8767…） | |
| 3 | 「数据处理 → 导入数据」，选一个真实的主文件夹（里面是 ZG00xx_… 子文件夹） | 预览里每个子文件夹一行，样品名和测量时间都对 | |
| 4 | 确认导入，打开一个样品 | 热力图、叠加谱、膜厚四宫格都出来；测量时间和仪器上的一致（不差 8 小时） | |
| 5 | 选 3 个样品点「批处理」 | 进度走完，落到对比页，曲线和柱状图都有 | |
| 6 | 对比页「导出脚本」，下载 zip，解压后在命令行里 `python plot.py` | 出一张图，中文不是方块 | |
| 7 | 关掉黑窗口，再双击一次 `run.bat` | 这次几秒就起来（[2/3] 显示「依赖就绪」），刚才导入的数据还在 | |
| 8 | 如果公司网络装依赖失败：窗口里的提示是否说清楚了怎么办 | 有一段「常见原因 / 可以手动执行」的说明，而不是一闪而过 | |
| 9 | （可选）设置页填你的模型网关，点「测试」 | 显示延迟和一句回复；连不上时说清楚是哪一步 | |

## 出问题时

- 窗口一闪就没了：在文件夹空白处按住 Shift 右键 → 「在此处打开 PowerShell 窗口」，输入 `.\run.bat` 回车，窗口就不会关
- 想重来：删掉项目里的 `.venv` 文件夹（只是依赖，不是数据），再双击 `run.bat`
- 数据在 `workspace\` 里，**不要删它**
